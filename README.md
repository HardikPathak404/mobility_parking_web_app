Mobility Parking Scheme Web Application (Django)
This project is a web-based application that allows residents to apply for a Mobility Parking Permit online. The system simplifies the application process by enabling users to register, log in, and submit required information through a structured digital form.

Features
- User registration and login
- Multi-section parking permit application form
- Form validation and structured data entry
- Clear and user-friendly interface

Technologies Used
- Python (Django Framework)
- HTML, CSS
- JavaScript
- SQLite (default Django database)

Purpose
Developed as part of an academic project to demonstrate how a digital solution can streamline mobility parking permit applications and improve accessibility.

How to Run
1. Install dependencies  
pip install -r requirements.txt

2. Apply migrations  
python manage.py migrate

3. Start the server  
python manage.py runserver


Then open: **http://127.0.0.1:8000**
